## 🚀 How to Install in Chrome

1. Open Chrome and navigate to: `chrome://extensions/`
2. Toggle **Developer mode** ON (top-right).
3. Click **"Load unpacked"** and select:
   `c:\Users\tarik\Desktop\MY TOOLS\amazon-seo-extension\src`
4. Visit any Amazon product page (`amazon.com/dp/...`).
5. Click the **TarikSEO Pro** ⚡ icon in your toolbar.
